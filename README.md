Relaxing Sleeping Sounds
Android Development Project
Αυτή η εφαρμογή δημιουργήθηκε με γνώμονα την απόλυτη απλότητα και την ευχρηστία σε περιβάλλοντα χαλάρωσης. Ο στόχος ήταν να φτιαχτεί ένα εργαλείο που μπορεί να χρησιμοποιηθεί άμεσα, ακόμα και από παιδιά, χωρίς την ανάγκη περίπλοκων ρυθμίσεων ή σύνδεσης στο διαδίκτυο.

The Vision Behind the App
Σχεδίασα το UI με μια "Kid-Friendly" προσέγγιση, χρησιμοποιώντας μεγάλες επιφάνειες αλληλεπίδρασης και καθαρά οπτικά στοιχεία. Η φιλοσοφία του σχεδιασμού βασίζεται στο "Focus on Silence": το περιβάλλον είναι σκόπιμα λιτό για να μην προκαλεί οπτική κόπωση πριν από τον ύπνο. Επιπλέον, η εφαρμογή είναι πλήρως Offline First, καθώς όλοι οι ήχοι είναι ενσωματωμένοι στο πακέτο εγκατάστασης, εξασφαλίζοντας ότι η χαλάρωση του χρήστη δεν εξαρτάται από το σήμα του Wi-Fi.
